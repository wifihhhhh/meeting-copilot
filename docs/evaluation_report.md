# 评估报告模板

## 数据集

- 10 场模拟会议记录：产品规划、技术评审、增长复盘、设计评审、项目周会等。
- 人工标注字段：决议事项、Action Items、负责人、截止时间。

## 指标

- 待办事项提取：Precision / Recall / F1
- 决议事项提取：Precision / Recall / F1
- RAG 问答：10 个跨会议问题，使用人工评分或 LLM-as-Judge 评分
- 完整性：人工 1-5 分

## 失败分析方向

- 多人同时发言，发言边界不清。
- 截止时间使用相对表达，例如“下周一”。
- 决议隐含在讨论中，没有出现“决定、确定、决议”等词。
- 同一个负责人有多个任务，模型可能合并或遗漏。
